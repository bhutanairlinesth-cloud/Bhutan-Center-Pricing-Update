# v11.1 — ปุ่มอัปเดตโลโก้

## สิ่งที่เพิ่ม

- Admin สามารถอัปโหลดโลโก้จากหลังบ้านได้
- โลโก้ใหม่จะแสดงบนหน้าเว็บ หน้าติดตามลูกค้า ใบเสนอราคา และ Invoice
- รองรับ PNG, JPG และ WEBP สูงสุด 2 MB
- มีปุ่มกลับไปใช้โลโก้เริ่มต้น
- เก็บไฟล์ใน Supabase Storage bucket ชื่อ `branding`

## ตั้งค่า Supabase หนึ่งครั้ง

1. Supabase → SQL Editor → New query
2. เปิดไฟล์ `supabase/MIGRATE_BRAND_LOGO.sql`
3. คัดลอกทั้งหมด วาง แล้วกด Run

## วิธีเปลี่ยนโลโก้

1. เข้าเว็บไซต์ด้วยบัญชี Admin
2. หลังบ้าน → ตั้งค่าราคา
3. ส่วน “โลโก้บริษัท” → อัปเดตโลโก้
4. เลือกไฟล์และรอข้อความบันทึกสำเร็จ

แนะนำใช้ PNG พื้นหลังโปร่งใส อัตราส่วนแนวนอน เพื่อให้แสดงผลสวยบนเว็บและเอกสาร A4
