# วิธีติดตั้ง v12.1 — ระบบพักเดี่ยว

## 1. อัปเดต Supabase ก่อน

เปิดไฟล์:

```text
supabase/MIGRATE_SINGLE_ROOM_SUPPLEMENT_V12_1.sql
```

คัดลอกทั้งหมด แล้วไปที่ Supabase:

```text
SQL Editor → New query → วาง SQL → Run
```

SQL จะเพิ่ม:

- `tour_packages.single_supplements_thb`
- `customer_tracking.single_room_count`
- `customer_tracking.single_supplement_per_person`
- `customer_tracking.single_supplement_total`

## 2. กรอกราคาพักเดี่ยวแต่ละแพ็กเกจ

เข้า:

```text
หลังบ้าน → โปรแกรมทัวร์ → แก้ไขแพ็กเกจ
```

กรอก:

- 3 Stars — ราคาพักเดี่ยวเพิ่มต่อท่านทั้งทริป
- 4 Stars — ราคาพักเดี่ยวเพิ่มต่อท่านทั้งทริป
- 5 Stars — ราคาพักเดี่ยวเพิ่มต่อท่านทั้งทริป

ตัวอย่าง:

```text
5 Days 4 Nights
3 Stars: 8,000 บาท/ท่าน
4 Stars: 12,000 บาท/ท่าน
5 Stars: 25,000 บาท/ท่าน
```

## 3. ใช้งานหน้าคำนวณ

หน้าคำนวณมี 2 ช่อง:

- จำนวนผู้พักเดี่ยว
- ส่วนต่างพักเดี่ยวต่อท่าน

ระบบดึงราคาตั้งต้นตามแพ็กเกจและระดับโรงแรมอัตโนมัติ แต่สามารถแก้เฉพาะเคสได้ เช่น ลูกค้า 8 คน ต้องการพักเดี่ยว 3 คน

```text
ส่วนต่างพักเดี่ยว 10,000 บาท × 3 คน = 30,000 บาท
```
