# Bhutan Center Pricing v12 — Customer Journey

เวอร์ชันนี้ปรับระบบติดตามลูกค้าตามกระบวนการทำงานจริง ตั้งแต่เสนอราคา จองตั๋ว ยื่นวีซ่า รับชำระเงิน จนถึง Feedback หลังเดินทาง

## ขั้นตอนหลักในระบบ

1. เสนอราคาและยืนยันการจอง
2. รับ Passport และรูปถ่าย
3. จองตั๋ว บันทึก PNR และรายชื่อผู้เดินทาง
4. ออก Invoice 1: ค่าตั๋วเครื่องบินทั้งหมด + ภาษีสนามบิน
5. บันทึกรับชำระงวดแรก และส่งตั๋วให้ลูกค้า
6. ส่ง Passport + รูป + ตั๋วให้ Land เพื่อยื่นวีซ่า
7. จัดทำ Invoice 2: ค่าแพ็กเกจทั้งหมดหักค่าตั๋วที่ชำระแล้ว
8. รับวีซ่า ส่งวีซ่า + Invoice 2 ให้ลูกค้า
9. รับชำระครบ ส่ง Itinerary และทำสถานะพร้อมเดินทาง
10. หลังเดินทาง ขอ Feedback และปิดจบงาน

## ก่อนใช้งาน

รันไฟล์นี้ใน Supabase SQL Editor หนึ่งครั้ง:

`supabase/MIGRATE_CUSTOMER_JOURNEY_V12.sql`

ไฟล์จะเพิ่มช่อง Milestone และสร้างตาราง `payment_transactions` สำหรับบันทึกรับชำระหลายครั้ง
