# Bhutan Center Unified V13.10 — Meta Custom Audience Playbook

เพิ่มคู่มือสร้าง Custom Audience ในหลังบ้าน โดยไม่แตะ Pricing / CRM / Invoice / Payment

## เพิ่มในเมนู
หลังบ้าน → การตลาด → Audience & Tags

## สิ่งที่เพิ่ม
- ขั้นตอนสร้าง Meta Custom Audience แบบทีละขั้น
- Audience แนะนำ 6 ชุด
- ปุ่มคัดลอกชื่อ Audience
- ปุ่มคัดลอก Rule/สูตร Audience
- Campaign Recipes สำหรับ Warm / Package / High Intent / Exclusion
- สถานะ Meta Pixel + CAPI ในหน้า Audience
- คำอธิบายการใช้ LINE กับ Meta อย่างถูกต้อง (ไม่ส่ง LINE userId ไป Meta โดยตรง)

## Audience แนะนำ
1. BC | Website Visitors | 30D
2. BC | Package Viewers | 30D
3. BC | LINE Intent | 14D
4. BC | Website Leads | 30D
5. BC | Visa Interest | 30D
6. BC | Confirmed-Paid | Exclusion (Phase 2 CRM/Customer List)
