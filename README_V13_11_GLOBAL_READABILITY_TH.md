# V13.11 – Global Back Office Readability

ปรับ Typography ทั้งระบบหลังบ้าน ไม่ใช่เฉพาะหน้า Audience

ครอบคลุม:
- Dashboard / Reports
- Pricing Desk
- Customer Tracking / CRM
- Quotation / Invoice / Payment
- Tour Programs / Hotels / Pricing Settings
- Website / LINE / Funnel / Audience
- Meta Pixel / Google Analytics & Ads / SEO
- Users / System Settings
- Sidebar / Buttons / Form / Table / Badge / Helper text

แนวทาง:
- ข้อความ 7–10px เดิมถูกยกขึ้นประมาณ 11–14px
- ข้อความ 11–14px เดิมถูกยกขึ้นประมาณ 14.5–16.5px
- Controls และตารางขยายให้สัมพันธ์กับตัวหนังสือ
- หัวข้อใหญ่ขึ้นเล็กน้อยโดยยังรักษาลำดับชั้น
- Mobile มีค่ารองรับแยก

ไม่มีการแก้ Logic, Database, Pricing, Customer Tracking, Meta, LINE หรือ Google
ไม่ต้อง Run SQL เพิ่ม
