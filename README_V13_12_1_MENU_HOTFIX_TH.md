# V13.12.1 — Sidebar Menu Hotfix

แก้ปัญหา Sidebar เมนู V13.12 ที่หัวข้อหมวดถูกตัด/ซ้อน/หลุดออกจากกล่อง เนื่องจาก CSS เก่าของเมนูเดี่ยวไปชนกับ Accordion ใหม่

แก้ไข:
- หัวข้อหมวดเรียงแนวนอนถูกต้อง
- ชื่อหมวดและคำอธิบายไม่ถูกตัด
- ตัวหนังสือเมนูใหญ่ขึ้นและอ่านง่าย
- เมนูย่อยไม่ซ้อนกัน
- รักษาระบบพับ/ขยายหมวดเดิม
- รองรับ Desktop / Mobile

`admin-app/src/index.css`
