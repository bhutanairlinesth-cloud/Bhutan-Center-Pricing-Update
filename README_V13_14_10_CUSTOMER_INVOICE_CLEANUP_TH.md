# V13.14.10 — Customer-facing Invoice Cleanup

ปรับข้อความและองค์ประกอบในเอกสาร PDF ที่ส่งให้ลูกค้าให้เหลือเฉพาะข้อมูลที่ลูกค้าจำเป็นต้องทราบ

- ลบข้อความนโยบายภายในเรื่อง VAT ต้องรับผ่านบัญชีบริษัทออกจากเอกสารลูกค้า (ระบบยังบังคับบัญชีบริษัทเหมือนเดิม)
- แสดงธนาคาร / ชื่อบัญชี / เลขที่บัญชีโดยตรงแทนการอธิบายนโยบายภายใน
- ลบคำ Invoice 3 / Invoice เพิ่มเติม และเลขลำดับภายในจากหัวข้อเอกสารเรียกเก็บเพิ่มเติม
- ลบสรุปยอดขายสะสม / ยอดขายรวมลูกค้าออกจากเอกสารเรียกเก็บเพิ่มเติม
- เอกสารค่าบริการตัดรหัส PTC / SRV ออก เหลือ รายการ / จำนวน / ราคาต่อหน่วย / จำนวนเงิน
- เปลี่ยน ADT / CHD ในตารางแพ็กเกจเป็น ผู้ใหญ่ / เด็ก
- ลดคำเชิงระบบ เช่น ก่อนจัด VAT / ฐาน VAT / หลังแยกค่าบริการ ให้เป็นข้อความทางการที่ลูกค้าเข้าใจง่าย
- เปลี่ยนยอดรวมเป็น “ยอดชำระทั้งสิ้น” และ “ยอดชำระงวดที่ 2” ตามประเภทเอกสาร
- ลบชื่อผู้จัดทำภายในออกจาก Footer ลูกค้า เหลือข้อมูลบริษัทและช่องทางติดต่อ

หมายเหตุ: การเปลี่ยนแปลงนี้เป็นการปรับ Customer-facing PDF เท่านั้น Logic การคำนวณ VAT, การแยกค่าบริการ และการบังคับบัญชีบริษัทเมื่อมี VAT ไม่เปลี่ยนแปลง
