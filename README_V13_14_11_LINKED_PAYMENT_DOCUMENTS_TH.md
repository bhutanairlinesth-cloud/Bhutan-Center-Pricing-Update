# V13.14.11 — เชื่อมโยงเอกสารค่าแพ็กเกจและเอกสารค่าบริการ

เป้าหมาย: ทำให้ลูกค้าเข้าใจว่าเอกสารค่าแพ็กเกจและเอกสารเรียกเก็บค่าบริการเป็นเอกสารคนละฉบับ แต่เป็นส่วนหนึ่งของการชำระสำหรับแพ็กเกจเดียวกัน

## เอกสารค่าแพ็กเกจงวดที่ 2
เมื่อ Agent เลือก VAT แบบแยกค่าบริการ จะแสดงสรุปตามลำดับดังนี้
- มูลค่าแพ็กเกจทั้งหมด
- ชำระแล้ว — งวดที่ 1 (ค่าตั๋วเครื่องบิน)
- ยอดคงเหลือหลังชำระงวดที่ 1
- แยกเรียกเก็บค่าบริการตามเลขที่เอกสารค่าบริการ
- ยอดชำระค่าแพ็กเกจงวดที่ 2

พร้อมกล่อง “เอกสารที่เกี่ยวข้อง” ระบุเลขที่เอกสารค่าบริการ และแจ้งว่าเป็นส่วนหนึ่งของการชำระสำหรับแพ็กเกจเดียวกัน

## เอกสารเรียกเก็บค่าบริการ
เพิ่มกล่อง “เอกสารที่เกี่ยวข้อง” ระบุเลขที่เอกสารเรียกเก็บค่าแพ็กเกจ และแจ้งว่าเอกสารฉบับนี้เป็นส่วนหนึ่งของการชำระสำหรับแพ็กเกจเดียวกัน

## หลักการข้อความลูกค้า
- ไม่ใช้คำว่า Invoice 3 ใน PDF ลูกค้า
- ไม่อธิบาย logic หลังบ้าน
- ไม่อธิบายเหตุผลด้านบัญชี/นโยบายภายใน
- แสดงเฉพาะความสัมพันธ์ของเอกสารและลำดับยอดที่ลูกค้าจำเป็นต้องทราบ

ไม่มีการเปลี่ยนสูตรราคา, VAT, วิธีรับชำระ หรือฐานข้อมูล และไม่ต้องรัน SQL เพิ่ม
