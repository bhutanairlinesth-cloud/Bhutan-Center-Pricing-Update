# Bhutan Center Unified V13.14.7 — Agent VAT Mode + Invoice 3

อัปเดตการคิด VAT สำหรับลูกค้า **Agent** ในส่วนค่าแพ็กเกจ โดยให้ผู้ใช้งานเลือกวิธีคิด VAT ตอนเปิด Invoice 2 / Full Payment ได้ 3 แบบ

## 1) ไม่คิด VAT
- ใช้ยอดค่าแพ็กเกจตามปกติ
- ไม่สร้าง Invoice ค่าบริการ

## 2) VAT 7% · ค่าแพ็กเกจทั้งหมด (Standard)
- คิด VAT 7% จาก **ยอดค่าแพ็กเกจที่เป็นฐาน VAT**
- ไม่รวมค่าตั๋วเครื่องบินและภาษีสนามบิน
- VAT แสดงอยู่ใน Invoice ค่าแพ็กเกจหลัก
- ไม่สร้าง Invoice 3 สำหรับค่าบริการ

ตัวอย่างฐานค่าแพ็กเกจ 100,000 บาท
- ค่าแพ็กเกจ 100,000
- VAT 7% = 7,000
- ยอด Invoice = 107,000 บาท

## 3) VAT 7% · ค่าบริการ (แยก Invoice 3)
ค่าบริการตามระยะเวลาแพ็กเกจ:
- 4 Days 3 Nights = 1,500 บาท/ท่าน
- 5 Days 4 Nights = 2,000 บาท/ท่าน
- 6 Days 5 Nights = 2,500 บาท/ท่าน

ระบบจะ **แยกยอดออกเป็น 2 เอกสาร** โดยค่าบริการเป็นส่วนหนึ่งของราคาแพ็กเกจเดิม ไม่ใช่ยอดขายเพิ่ม

ตัวอย่าง 5D4N จำนวน 4 ท่าน ฐานค่าแพ็กเกจ 100,000 บาท
- ค่าบริการ = 2,000 × 4 = 8,000 บาท
- Invoice ค่าแพ็กเกจหลัก = 100,000 - 8,000 = 92,000 บาท
- Invoice 3 ค่าบริการ = 8,000 บาท
- VAT 7% ของค่าบริการ = 560 บาท
- Invoice 3 รวม = 8,560 บาท
- ยอดเรียกเก็บรวม = 92,000 + 8,560 = 100,560 บาท

ดังนั้น VAT ที่เพิ่มจริงคือ 560 บาทเท่านั้น และค่าบริการ 8,000 บาทไม่ถูกนับเป็นยอดขายซ้ำ

## พฤติกรรมเอกสาร
- Invoice ค่าแพ็กเกจหลักจะแสดงรายการหักค่าบริการที่ย้ายไป Invoice 3
- Invoice 3 แสดงเฉพาะ `ค่าบริการ + VAT 7%`
- Invoice 3 ใช้บัญชีบริษัทสำหรับรับชำระ
- ในหน้ารับชำระ สามารถเลือก Invoice 3 เพื่อบันทึกยอดชำระแยกจาก Invoice ค่าแพ็กเกจได้
- ระบบจะถือว่าค่าแพ็กเกจชำระครบเมื่อทั้ง Invoice ค่าแพ็กเกจหลักและ Invoice 3 ชำระครบ
- หาก Invoice 3 มีรายการรับชำระแล้ว ระบบจะไม่อนุญาตให้เปลี่ยน VAT mode จนกว่าจะตรวจสอบ/ย้อนรายการรับชำระ เพื่อป้องกันยอดเอกสารคลาดเคลื่อน
