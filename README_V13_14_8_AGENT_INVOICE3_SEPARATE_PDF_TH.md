# V13.14.8 — Agent Invoice 3 แยกไฟล์ + VAT ใช้บัญชีบริษัทเท่านั้น

อัปเดตตาม workflow Agent / Partner:

- เมื่อเลือก `VAT 7% · ค่าบริการ (แยก Invoice 3)` ระบบยังคงหักค่าบริการออกจาก Invoice 2 และสร้าง Invoice 3 แยกต่างหาก
- เพิ่มปุ่มบน Invoice 2: `เปิด Invoice 3 · ไฟล์ค่าบริการ + VAT`
- Invoice 3 มีปุ่ม `พิมพ์ Invoice 3 / บันทึก PDF แยก` เพื่อให้บันทึกเป็นไฟล์ PDF คนละไฟล์กับ Invoice 2 อย่างชัดเจน
- Invoice 2 มีเฉพาะยอดค่าแพ็กเกจหลังหักค่าบริการออกแล้ว
- Invoice 3 มีเฉพาะ `ค่าบริการ + VAT 7%`
- เอกสารใดก็ตามที่มี VAT จะบังคับใช้ `บัญชีบริษัท` เท่านั้น และไม่สามารถเปลี่ยนเป็นบัญชีเจ้านายจากหน้า Invoice ได้
- สำหรับโหมด Service Split: Invoice 2 ไม่มี VAT จึงยังใช้บัญชีตาม workflow ปกติได้ ส่วน Invoice 3 ที่มี VAT จะใช้บัญชีบริษัทเท่านั้น
- โหมด `VAT 7% · ค่าแพ็กเกจทั้งหมด (Standard)` จะบังคับบัญชีบริษัททั้ง Invoice หลัก เพราะ Invoice หลักนั้นมี VAT

ไม่มีการเปลี่ยน schema ฐานข้อมูลในเวอร์ชันนี้ หากได้รัน migration ของ V13.14.7 แล้ว ไม่ต้องรัน SQL เพิ่ม
