# V13.14.9 — ปรับถ้อยคำและรูปแบบเอกสาร Agent VAT

## ปรับ Invoice งวดที่ 2 เมื่อเลือก VAT แบบค่าบริการแยกเอกสาร
- ตัดรายละเอียดการหักค่าบริการ / อ้างอิง Invoice 3 ออกจากเอกสารลูกค้า
- ไม่แสดงรายการคำนวณภายใน เช่น ค่าแพ็กเกจทั้งหมด, ยอดก่อน VAT, หักค่าบริการ ฯลฯ ในโหมดนี้
- แสดงเพียงหัวข้อ `การชำระงวดที่ 2 — ค่าแพ็กเกจ`
- แสดงรายการเดียว `ค่าแพ็กเกจงวดที่ 2` ซึ่งเป็นยอดหลังแยกค่าบริการแล้ว
- ใช้ยอดชำระด้านล่างของเอกสารเป็นยอดสุทธิของงวดที่ 2

## ปรับเอกสารค่าบริการให้เป็นทางการ
- ชื่อเอกสาร: `เอกสารเรียกเก็บค่าบริการ`
- หัวตาราง: `รายละเอียดค่าบริการ`
- สรุปยอด:
  - `รวมค่าบริการ`
  - `ภาษีมูลค่าเพิ่ม (VAT) 7.00%`
  - `ยอดชำระสุทธิ`
- ตัดคำว่า `Invoice 3` ออกจากเนื้อหาเอกสารที่ลูกค้าเห็น
- ตัดหมายเหตุภายในเรื่องการไม่นับยอดขายซ้ำออกจาก PDF ลูกค้า
- ปรับ layout แถวรวม / VAT / ยอดสุทธิให้ตัวเลขและข้อความแยกคอลัมน์ อ่านง่ายขึ้น

## หลังบ้าน
- ตัวเลือก VAT เปลี่ยนคำเป็น `VAT 7.00% · ค่าบริการ (แยกเอกสารค่าบริการ)`
- ปุ่มเปิดเอกสารใช้คำว่า `เปิดเอกสารค่าบริการ`
- เอกสารที่มี VAT ยังคงบังคับรับชำระผ่านบัญชีบริษัทเท่านั้น
