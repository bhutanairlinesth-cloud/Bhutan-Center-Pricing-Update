# V13.18.8 – Philosophy Image Fill Hotfix

แก้ปัญหาภาพในส่วน WHY BHUTAN CENTER ดูเหมือนขาด/มีพื้นที่ว่างด้านล่าง

## สาเหตุ
`philosophy-media` ใช้ `min-height` แต่รูปภายในยังไม่ถูกวางแบบเต็มกรอบ ทำให้บางหน้าจอมีพื้นที่พื้นหลังโผล่ด้านล่าง จนดูเหมือนภาพถูกตัดหรือขาด

## สิ่งที่แก้
- ทำให้รูปใน `.philosophy-media` วางแบบเต็มกรอบด้วย `position:absolute; inset:0;`
- ให้ภาพ cover เต็มพื้นที่เสมอ
- ปรับ overlay ด้านล่างให้นุ่มขึ้น
- เพิ่มเงาเล็กน้อยให้ caption
- ปรับความสูงสำหรับ Tablet / Mobile ให้สมดุลขึ้น

## ไฟล์ที่แก้
- `app/globals.css`

ไม่ต้องรัน SQL
