# Bhutan Center V13.18 — Interactive Bhutan Map + City Guides

เพิ่มระบบหน้าเที่ยวภูฏานให้เป็น Destination Explorer แบบกดแผนที่ได้

## เพิ่มใหม่
- แผนที่ภูฏานแบบ Interactive บนหน้า `/bhutan-attractions`
- กด Paro / Thimphu / Punakha / Gangtey แล้วไปหน้าเมืองโดยตรง
- หน้าเมืองใหม่ 4 หน้าแบบ Dynamic
- Hero ภาพใหญ่ + ประวัติย่อ + สถานะของเมือง + ประชากรระดับ Dzongkhag ปี 2025
- รายการสถานที่ท่องเที่ยวเด่น 4 แห่งต่อเมือง
- แผนที่แสดงตำแหน่งเมืองปัจจุบัน
- แนะนำเมืองอื่นต่อท้ายเพื่อให้ลูกค้าสำรวจต่อ
- Responsive สำหรับมือถือ: marker บนแผนที่จะย่อ และมีรายการเมืองด้านล่างให้กดง่าย
