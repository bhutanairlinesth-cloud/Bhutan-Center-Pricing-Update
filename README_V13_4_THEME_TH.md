# Bhutan Center Unified V13.4 — Website-aligned Back Office Theme

Patch นี้ปรับเฉพาะ Design System ของ Back Office ให้ใช้ภาษาภาพเดียวกับเว็บไซต์ Bhutan Center:

- Prompt เป็นฟอนต์หลักทั้งหน้าเว็บและหลังบ้าน
- Champagne Gold / Warm Ivory / Cream / Soft Brown
- Sidebar จากเขียวเข้มเป็น Soft Brown
- Active menu เป็น Champagne Cream + Gold accent
- พื้นหลัง Back Office เป็น Warm Ivory
- Card / Panel เป็น White Ivory พร้อมขอบครีมและ shadow แบบเดียวกับ Website
- ปุ่มหลักเป็น Champagne Gold pill
- Form focus ใช้ Gold ring
- Funnel / Retargeting / Meta Pixel ใช้ theme เดียวกัน
- Login เปลี่ยนจาก Green SaaS ไปเป็น Bhutan Center Brown/Gold
- สี Success / Warning / Error เชิงสถานะยังคงแยกได้ เพื่อไม่กระทบความเข้าใจของข้อมูล

ไม่เปลี่ยน Database, Pricing logic, Customer Tracking, Quotation, Invoice, Payment, LINE หรือ Meta logic และไม่ต้อง Run SQL ใหม่
