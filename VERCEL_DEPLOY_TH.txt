Bhutan Center Unified V13 — Vercel Deploy
=========================================

โปรเจกต์นี้เป็น Unified Project:
- /       = Public Website (Next.js)
- /admin  = Bhutan Pricing / Back Office (Vite SPA)

ค่าที่ควรใช้:
Framework Preset: Next.js
Build Command: npm run build
Output Directory: ปล่อยเป็นค่า Default ของ Next.js (ห้ามตั้งเป็น dist)
Install Command: npm install
Root Directory: เว้นว่าง

คำสั่ง npm run build จะ Build admin-app ก่อน แล้วจึง Next.js Website

Environment Variables สำคัญ:
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY หรือ VITE_SUPABASE_ANON_KEY
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

หลัง Commit ใหม่ให้ Deploy commit ล่าสุด และทดสอบทั้งหน้า / และ /admin
